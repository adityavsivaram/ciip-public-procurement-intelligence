# Contributing

This repository is primarily a research and methodology publication.

Useful contributions include:

- methodological critique
- reproducibility improvements
- data-quality observations
- false-positive test cases
- indicator definitions
- public-source corrections

Do not submit:

- confidential company data
- personal data
- credentials
- client evidence
- private procurement records

When proposing a new indicator, document:

1. indicator definition
2. minimum data fields
3. eligibility gates
4. calculation/rule
5. benign explanations
6. required corroborating evidence
7. permitted conclusion state
8. false-positive test cases
