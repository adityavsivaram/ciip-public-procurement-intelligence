# Data

No raw San Francisco bulk datasets are stored in this repository.

## Why

The source files are large and may change over time. The authoritative source should remain DataSF.

## Source datasets used in Study #001

- Purchasing Commodity Data
- Vendor Payments (PO Summary)
- Vendor Payments (Vouchers)
- Supplier Contracts

Use the source catalog for dataset references and source links.

The analytical outputs in this repository are derived from public source data and the documented CIIP methodology.
