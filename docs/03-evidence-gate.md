# Evidence Gate

| State | What it means | Permitted language |
|---|---|---|
| Signal | Analytical pattern detected | Potential signal; investigation priority |
| Investigation Priority | Signal survives identity/comparability checks | Warrants documentary review |
| Evidence-Supported Discrepancy | Primary evidence independently corroborated | Evidence indicates discrepancy |
| Potential Exposure | Quantified amount linked to validated issue | Potential exposure |
| Validated Commercial Impact | Management validates issue/action | Validated commercial impact |
| Recovery / Correction | Documented financial/control correction | Recovered/corrected amount |
| Cleared / Explained | Signal resolved by evidence | Cleared/explained |

## Prohibited analytical shortcuts

Do not automatically convert:

- anomaly → leakage
- variance → overbilling
- exposure → savings
- savings opportunity → recovery
- supplier concentration → wrongdoing
- threshold clustering → intentional splitting

The evidence requirement rises with the materiality of the claim.
